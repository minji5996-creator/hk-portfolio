# 한국경제 AI 교육 포트폴리오

`article.html`, `image.html`, `video.html`, `final.html`은 각각 독립된 HTML 문서입니다. `index.html`은 기사 페이지와 동일한 시작 페이지입니다. HTML을 브라우저로 열어 사용할 수 있습니다.

- 기사: 대표 기사와 세 편의 학습 에세이. 링크 선택 시 전문 표시.
- 이미지: 세 개의 AI 생성 샘플. 이미지 선택 시 확대.
- 영상: 콘셉트 이미지와 스토리보드. 실제 영상 파일은 아직 없습니다.
- Final project: 개요, 역할, 제작 과정 소개.

현재 콘텐츠는 임시 샘플이며, 실제 교육 결과물이나 보도 기사가 아닙니다. 웹 업로드·로그인·서버 저장 기능은 포함하지 않은 정적 포트폴리오입니다.

내용은 각 HTML에서 수정하고 이미지 파일은 `assets`에서 교체하세요. 페이지 생성 원본은 `build-pages.cjs`입니다. 이 파일을 수정하고 `node build-pages.cjs`를 실행하면 모든 HTML을 재생성하므로 HTML을 직접 수정한 뒤에는 재생성하지 마세요.

`node build.cjs`는 배포용 파일을 `dist`에 복사하고 내부 링크를 확인합니다. 디자인은 `style.css`, 상세보기 동작은 `app.js`에 있습니다. Google Fonts가 연결되지 않는 환경에서는 시스템 글꼴로 표시됩니다.
